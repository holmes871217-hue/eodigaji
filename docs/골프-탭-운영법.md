# 골픽(골프 탭) 운영법

## 무엇을 보여 주나
- **국내**: 내 출발지(마이 탭의 검색 위치)에서 차로 정한 시간(기본 2시간, 1시간~3시간) 안에 있는 골프장을 날짜별 **1인 총비용 낮은 순**으로 보여 줍니다. 개수 제한 없이 20곳씩 더 보기, 전체 개수 표시.
- **해외**: 나라·도시를 골라 골프 상품을 **가격 낮은 순**으로 보여 줍니다. 인천 출발 항공 시간(직항/경유), 공항→골프장 도로 거리·시간을 함께 보여 줍니다.

## 해외(2026-11-23 개편)
- **골프장**: 몽키트래블 공개 목록 API(`/api/search/productList.php`, robots.txt 허용) — 태국·대만·필리핀·베트남·괌·사이판·일본 687곳. 사진·등급·평점·1인당 가격, 홀 수는 상세 화면 제목에서(캐시 `tools/golf/data/mt-holes.json`). "[예약 대행]" 상품 가격은 대행 수수료라 1인당 가격에서 뺀다.
- **항공권**: 공항 표 `AIRPORTS`(lib.mjs) 중 골프장 주변 공항(가장 가까운 곳+150km)을 비교해 추천가가 가장 싼 공항을 고른다. 추천가 = 네이버 항공권 인천 왕복 최저가(2주 뒤 첫 목요일 출발 4박, 그 1주 뒤 4박 두 번 조회. 차이 40% 넘으면 낮은 값, 아니면 평균). 매일 `tools/golf/naver-fares.mjs` 가 서울 MCP 서버에 물어 `tools/golf/data/flights.json` 에 저장. 네이버 결과가 없는 공항은 이전(구글 항공편) 값을 두고 화면에 출처를 "구글 항공편"으로 표시.
- **근처 숙소**: 부킹닷컴 도시별 평점순 30곳(`tools/golf/data/hotels.json`, 수동 갱신) 중 골프장에서 가까운 10곳 → 평점 높은 순 5곳.
- **패키지 상품**: 골프몬(항공 포함, Firecrawl 한국 위치로 매일) + 티스캐너 해외 상품.
- 해외 "가는 날짜"는 항공권·숙소·몽키트래블 링크 날짜와 패키지 출발일 필터에 쓰인다(표시 가격은 모아 둔 날짜 기준).

## 계산 규칙
- 1인 총비용 = 1인 그린피 + 카트비÷4 + 캐디피÷4. 카트비·캐디피를 모르면 그린피만 더하고 "카트비·캐디피 미포함"으로 표시합니다.
- 같은 골프장이 두 플랫폼에 있으면 하나로 합치고(이름이 같거나, 위치가 1.5km 안) 싼 값을 씁니다. 두 가격과 링크를 모두 보여 줍니다.
- 차 시간: 출발지가 거점 도시이면 카카오 길찾기 값("카카오 길찾기" 표시), 지도로 고른 위치·GPS면 직선거리 추정("직선거리 추정" 표시).
- 항공·거리 정보가 없으면 "확인 불가"로 표시하고 지어내지 않습니다.

## 파일
- 수집기: `tools/golf/collect.mjs`, 규칙: `tools/golf/lib.mjs`, 점검: `node tools/check-golf.mjs`
- 앱: `app/js/core/golf.js`(계산), `app/js/ui/golf.js`(화면), 자료 `app/data/golf.json`
- 자동 실행: `.github/workflows/golf.yml` (수동 실행도 가능)

## 항공 시간 새로 받기
항공권 **가격**은 매일 자동(네이버). 비행 **시간**(직항/경유)만 Claude 세션에서 구글 항공편 검색으로 받아 `tools/golf/data/flights.json` 에 저장합니다. 새 도시가 생기면 `tools/golf/lib.mjs` 의 `CITY_AIRPORTS` 에 공항을 넣고 그 공항도 조회합니다.

## 화면 (국내, 2026-11-24)
- 골프 탭에서는 왼쪽 위 이름이 "놀픽" 대신 "골픽". 화면 안 큰 제목은 없음.
- "라운딩 일정"(날짜)과 "출발:"을 한 줄에 반씩.
- 카드: 왼쪽 위 동그란 순위 숫자(추천 탭 여행지 카드처럼 1, 2, 3…), 총비용 아래 "그린피 + 카트비 + 캐디피(또는 노캐디)(플랫폼)" 1인 내역 한 줄.
- 18홀이 안 되는 곳(9홀×2 "-퍼9"·"(P9)", 6홀×3, 3홀, 파크골프, 홀 수 18 미만)은 수집과 화면 모두에서 뺀다(2026-11-24).
  - 티스캐너에 "18홀"로 등록돼 있어도 코스 길이(course_scale_meter)가 4,000m 미만이면 뺀다(예: 골드리버 3,564m, "18홀 진행(6홀*3회)").
  - 티타임 상품 글에 "6홀*3회"·"9홀X2"·"9홀 2회"가 적힌 티타임은 뺀다(티스캐너·티업엔조이·골팡).
- 카드 제목 옆 특가 꼬리표: 티스캐너 상품 표시 "특가"·"이벤트"·시크릿 할인, 티업엔조이 상품 글의 "특가"·"이벤트"·"시크릿 특가".
- 카드 "HH:MM 티오프": 가장 싼 값으로 칠 수 있는 티타임 중 가장 빠른 시각(티스캐너·골팡·골프몬 목록, 티업엔조이는 가장 쌀 때만 골프장 티타임 API `/api/proxy/booking/search/club/teetimes`).
- 카드를 누르면 상세: 사진 최대 5장(티스캐너 골프장 사진, 옆으로 넘김), 플랫폼별 가격과 예약 링크.
- 골프몬은 **Firecrawl 없이** 서울 서버(`servers/golfmon`, 플레이라이트)로 받는다. 골프몬 작업 `.github/workflows/golfmon.yml`(매일 03:30)이 받고, 골프 작업(04:30)은 저장본만 읽는다.
- 골프몬 국내 양도는 **14일에 한 번 30일치**를 받아 `tools/golf/data/golfmon-dom.json`에 저장하고, 그 사이 매일은 저장본(지난 날짜 뺀 것)을 쓴다(2026-11-24 운영자 지시: Firecrawl 크레딧 최소화). 받을 때는 달력 화면 1번으로 매물 있는 (지역·날짜) 칸만 골라 누른다. 달력을 못 읽으면 7일치만. 강제로 새로 받기: `GOLF_GM_FORCE=1`.
- 골프몬만 가격이 있는 먼 날짜(8~30일 뒤)도 날짜로 고를 수 있다(golf.json `dates`에 포함).

## 알려진 한계
- 골프몬: 한국 밖 접속을 막아("서비스 이용 지역 안내" 403) GitHub(미국 서버)에서 모을 수 없음. 한국 위치로 우회 접속하는 방법은 이 작업 환경 권한에서 허용되지 않음.
- 김캐디·네이버 예약: robots.txt 가 일반 수집기를 전부 막음(`Disallow: /`) → 수집하지 않고 "네이버에서 찾기" 링크로 연결.
- XGOLF·골프몬·카카오골프·KKday 는 자동 접속을 막아 가격을 모으지 않습니다.
- 골팡 가격이 1인 기준인지는 골팡 화면 표기("그린피")와 티스캐너 같은 날 가격이 비슷한 것으로 판단했습니다(로그인해야 보이는 상세는 확인하지 않음).
- 해외 상품가는 상품마다 포함 내용(항공·숙박·식사)이 달라, 제목·옵션에 적힌 항공 포함 여부만 표시합니다.

## 해외 화면 (2026-11-24 개편)
- 상단: 왼쪽 "라운딩 일정"(달력), 오른쪽 "상품"(골프장/패키지 아이콘). 국내/해외 탭에 테두리.
- 머무는 기간 칩: 1박(36홀)·2박(54홀, 기본)·3박(72홀). N박 = 라운딩 N+1번, 1인 골프 비용 × 라운딩 횟수 + 항공권으로 정렬.
- 일정 가정: 고른 날 = 첫 라운딩. 항공권은 전날 출발, 3일 라운딩 뒤 마지막 날 **17시 이후 출발 귀국편**(다음날 한국 도착) 중 최저가. 숙소는 전날 체크인 3박.
- 항공권은 앱이 서울 서버 `/fare`(servers/golfmon)에 물어 네이버 항공권 MCP 서버로 실시간 조회(같은 질문 6시간 저장). 조회 전에는 모아 둔 예상값으로 계산하고 "(예상)" 표시.
- 추천순: 1인 골프 비용 + 왕복 항공권 합계 낮은 순(패키지는 항공 불포함이면 항공권을 더함).
- 카드: 국내와 같은 모양(왼쪽 위 순위, 오른쪽 사진, 아래 한 줄 내역). 제목 [나라-도시] 이름은 한 줄(넘치면 자간 → 글자 크기 → … 순으로 줄임).
- 골프장 홀 수 필터: 18홀 이상(기본)·9홀·전체.
- 패키지: 같은 사이트·같은 제목(출발일만 다른 것)은 가장 싼 하나로 묶고 "같은 상품 출발일 N개 중 최저" 표시.
- 상세 사진: 몽키트래블 상세 화면의 골프장 사진 최대 6장(`mt-holes.json` 의 photos, pv:2).

- 국내 상세 "네이버에서 찾기": 골프장 이름만 검색(예: 360도CC). (P)·괄호·노캐디 같은 말은 떼고, CC·GC·골프 같은 말이 없으면 CC 를 붙인다.
