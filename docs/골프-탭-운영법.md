# 골픽(골프 탭) 운영법

## 무엇을 보여 주나
- **국내**: 내 출발지(마이 탭의 검색 위치)에서 차로 정한 시간(기본 2시간, 1시간~3시간) 안에 있는 골프장을 날짜별 **1인 총비용 낮은 순**으로 보여 줍니다. 개수 제한 없이 20곳씩 더 보기, 전체 개수 표시.
- **해외**: 나라·도시를 골라 골프 상품을 **가격 낮은 순**으로 보여 줍니다. 인천 출발 항공 시간(직항/경유), 공항→골프장 도로 거리·시간을 함께 보여 줍니다.

## 자료 출처 (모두 로그인 없이 공개된 화면이 쓰는 자료)
| 항목 | 출처 | 갱신 |

| 국내 날짜별 최저 그린피·티 수·골프장 좌표 | 티스캐너 공개 API (`foapi.teescanner.com`) | 매일 04:30 |
| 카트비·캐디피·주소·전화 | 티스캐너 골프장 정보 | 7일마다 |

| 항공 시간 | 구글 항공편 검색(인천 출발, 2026-12-10편 기준) — `tools/golf/data/flights.json` | 수동(아래) |
| 환율 | ExchangeRate-API (open.er-api.com) | 매일 |

## 계산 규칙
- 1인 총비용 = 1인 그린피 + 카트비÷4 + 캐디피÷4. 카트비·캐디피를 모르면 그린피만 더하고 "카트비·캐디피 미포함"으로 표시합니다.
- 같은 골프장이 두 플랫폼에 있으면 하나로 합치고(이름이 같거나, 위치가 1.5km 안) 싼 값을 씁니다. 두 가격과 링크를 모두 보여 줍니다.
- 차 시간: 출발지가 거점 도시이면 카카오 길찾기 값("카카오 길찾기" 표시), 지도로 고른 위치·GPS면 직선거리 추정("직선거리 추정" 표시).
- 항공·거리 정보가 없으면 "확인 불가"로 표시하고 지어내지 않습니다.

## 파일
- 수집기: `tools/golf/collect.mjs`, 규칙: `tools/golf/lib.mjs`, 점검: `node tools/check-golf.mjs`
- 앱: `app/js/core/golf.js`(계산), `app/js/ui/golf.js`(화면), 자료 `app/data/golf.json`
- 자동 실행: `.github/workflows/golf.yml` (수동 실행도 가능)

## 항공 시간 새로 받기
GitHub Actions 에는 항공 조회 키가 없어, Claude 세션에서 구글 항공편 검색으로 받아 `tools/golf/data/flights.json` 에 저장합니다. 새 도시가 생기면 `tools/golf/lib.mjs` 의 `CITY_AIRPORTS` 에 공항을 넣고 그 공항도 조회합니다.

## 화면
- 탭 이름 "골픽". 카드 왼쪽 위 순위(1위~), 오른쪽 사진(티스캐너·티업엔조이 공개 사진, 없으면 깃발 그림).
- 카드를 누르면 가장 싼 가격을 올린 플랫폼의 그 골프장·그 날짜 예약 화면으로 이동. 아래 칩으로 다른 플랫폼 가격과 "네이버에서 찾기"도 열 수 있다.

## 알려진 한계
- 골프몬: 한국 밖 접속을 막아("서비스 이용 지역 안내" 403) GitHub(미국 서버)에서 모을 수 없음. 한국 위치로 우회 접속하는 방법은 이 작업 환경 권한에서 허용되지 않음.
- 김캐디·네이버 예약: robots.txt 가 일반 수집기를 전부 막음(`Disallow: /`) → 수집하지 않고 "네이버에서 찾기" 링크로 연결.
- XGOLF·골프몬·카카오골프·KKday 는 자동 접속을 막아 가격을 모으지 않습니다.
- 골팡 가격이 1인 기준인지는 골팡 화면 표기("그린피")와 티스캐너 같은 날 가격이 비슷한 것으로 판단했습니다(로그인해야 보이는 상세는 확인하지 않음).
- 해외 상품가는 상품마다 포함 내용(항공·숙박·식사)이 달라, 제목·옵션에 적힌 항공 포함 여부만 표시합니다.
