# 인원(inwon.kr) 분석 — 골픽 "같은 티타임 예약처별 가격 비교" 설계용

조사일 2026-11-24. 인원 공개 화면(홈, `/list?r=sg&d=…`, `/c/k42?d=…`), 소개(`/about`), 자주 묻는 질문(`/faq`), 노트 2편(`/notes/same-tee-different-price`, `/notes/where-to-book`), 약관(`/terms`), robots.txt, sitemap.xml 을 읽고 정리했다. 인원이 내부에서 어떻게 모으는지는 공개돼 있지 않아 **알 수 없음**으로 적는다.

## 0. 한 줄 요약
인원 = 예약처 4곳(네이버 예약·카카오골프예약·골프존 티스캐너·티업엔조이)의 **티타임 한 줄 한 줄**을 "골프장·날짜·시각·코스"로 맞춰 예약처별 1인 그린피와 조건을 나란히 보여 주고, 양도(골프몬·골팡)는 같은 골프장 화면의 **별도 묶음**으로 보여 준다. 예약은 받지 않고 예약처 화면으로 보낸다. 운영 보어(VOHR), 비교 골프장 425곳.

## 2. 같은 티타임 맞추기(매칭)
- 키: **골프장 + 날짜 + 시각 + 코스 이름**(코스가 여럿인 골프장은 코스별, 예: 07:20 스윙 / 07:20 코브). 비교 조건은 "4명·정규 18홀".
- 골프장마다 인원 자체 번호(`/c/k42`)를 두고 예약처별 번호를 짝지어 둔다(예: k42 ↔ 티스캐너 golfclub_seq 577 ↔ 티업엔조이 club 248). 짝지은 골프장 수: 카카오 340, 티스캐너 378, 네이버 222, 티업엔조이 173, 골프몬 336, 골팡 226(노트 기준).
- 조건 문구(회원가입·선결제·최소 인원·특가·노캐디·카트비 별도)를 함께 저장하고, **조건이 다르면 "어디가 싸다"고 하지 않고 무엇이 다른지**를 보여 준다(FAQ).
- 인원 집계: 두 곳 이상에서 판 같은 티타임 21,808개 중 33%가 예약처마다 그린피가 달랐고 차이는 보통 1인 1만원(2026-10 노트).
- 같은 예약처 안에서도 인원·결제 방식에 따라 가격이 갈린다(티스캐너 4명 선결제 129,000 / 3명 선결제 149,000 / 현장결제 169,000).

## 3. 예약처별 가격 비교 화면
- 목록 카드: 이름·평점·지역·운영형태·홀 수, "예약처 N곳 중 최저 X원", 잔여 팀 수, 화면 만든 시각. 한 곳만 있으면 "티업엔조이 기준 · 카카오골프 조건 미확인".
- 골프장 화면 위 비교 상자: 가장 싼 티타임 하나를 골라 예약처별 가격(최저가 표시, 회원가입 필요·선결제 꼬리표) + "티스캐너에서 예약 — 이동 후 07:20 · 스윙 코스를 선택하세요" 안내.
- 시간표: 시각·코스·최저가 한 줄, 펼치면 예약처별 가격·조건·예약 › 링크. 링크는 그 예약처의 그 골프장·그 날짜 화면(티업엔조이는 bookingSeq 까지).
- 골프장 정보: 주소·운영·홀 수·전화·카트비·캐디피·특징(3인 가능, 당일 예약)·예약처별 예약 가능 여부.

## 4. 양도 합치는 방식
- 같은 골프장 화면에 "양도 34팀 140,000원~"처럼 **따로 묶어서** 보여 준다. 예약처 가격 비교 상자에는 섞지 않는다(FAQ: "예약과 따로, 같은 화면에 함께").
- 이유(노트): 양도는 판매자 연락·매물별 위약 규정이라 조건이 달라서.

## 5. 수집·갱신 구조 (보이는 것만)
- 서버에서 그린 화면(Next.js)이고 "이 화면은 11월 24일 11:31에 만든 화면이에요"처럼 생성 시각을 표시. 예약처·날짜마다 확인 시각이 다르다고 적음.
- 검색엔진에는 앞으로 8일치 날짜 화면만 허용(robots.txt), FAQ 통계는 "앞으로 2주".
- 예약처별 수집 상태 화면(`/status`) 운영. 내부 API(`/api/`)는 수집 금지.
- 실제 수집 방법·주기·서버 위치: **알 수 없음**.

### 자료 구조(제안)
- `courses`: 우리 골프장 id, 예약처별 id(ts·tu·gp·gm), 코스 이름 별칭표(예약처마다 코스 이름이 다르므로).
- `teetimes`: 골프장, 날짜, 시각(HH:MM), 코스, 홀, 최소~최대 인원, 예약처, 1인 그린피, 조건 꼬리표[], 예약 링크, 확인 시각.
- `transfers`: 골프장, 날짜, 시각, 가격, 판매처(골팡·골프몬), 링크 — 비교와 따로.
- 파일 크기: 지금처럼 정적 JSON 하나에 티타임을 다 넣으면 너무 커진다. 목록용(골프장·날짜별 최저가·예약처 수·잔여 팀 수)과 상세용(골프장·날짜별 시간표 파일, 상세를 열 때만 불러옴)으로 나눈다.
