# 최근 변경 내용 (2026-11-23)

## 0. 골프 탭 새로 생김 (특가 → 골프 → 마이)
- **국내**: 출발지에서 차로 1시간~3시간(기본 2시간) 안의 골프장을 날짜별로, **1인 총비용(그린피+카트비÷4+캐디피÷4) 낮은 순**으로 보여 줘요. 20곳씩 더 보기, 전체 개수 표시.
- 가격 출처: 티스캐너(18홀 티타임만)·골팡(양도·부킹 글). 같은 골프장은 하나로 합치고 두 가격·링크를 다 보여 줘요.
- 차 시간: 카카오 길찾기(다음 토요일 06:00 출발 예상) 값이 있으면 그 값, 없으면 "직선거리 추정"이라고 표시해요.
- **해외**: 나라·도시를 고르면 골프 상품을 가격 낮은 순으로 보여 줘요. 인천 출발 항공 시간(직항/경유), 공항→골프장 도로 거리·시간, 현지 통화 환산(출처·시각 표시)도 같이 보여 줘요.
- 자료는 매일 04:30 자동으로 다시 모아요. 설명: `docs/골프-탭-운영법.md`


## 1. 탭·버튼 정리
- 아래 탭 "찜"이 **"찜·코스"**로 바뀌었어요.
- "전국 지역 트렌드 지도 보기"와 "여행 코스 자동 만들기"가 추천 탭에서 **찜·코스 탭 위쪽**으로 옮겨졌어요(찜이 하나도 없어도 보여요).
- 좁은 폰에서 탭 이름이 두 줄로 꺾이던 것을 한 줄로 고쳤어요.

## 2. 내 취향을 사람별로
- 마이 탭 "함께 가는 사람" 카드마다 **"○○의 취향(선택)"** 칩이 생겼어요.
- 추천 점수에는 사람의 가중치(1~5)대로 평균해서 반영돼요. 취향을 안 고른 사람은 중립이에요.
- 반영 강도를 높였어요: 취향 1개에 맞으면 **+60%**, 2개 이상이면 **+90%**(전에는 +25%·+35%).
- 전에 전체 공통으로 골라 둔 취향은 첫 번째 사람("나")의 취향으로 자동 이동해요.
- 칩이 카드 밖으로 넘치던 것을 카드 안에서 줄바꿈되게 고쳤어요.

## 3. 여행 코스에 맛집·카페
- 찜해 둔 맛집은 **점심 시간대**에 방문으로 들어가고, 바로 다음에 카페가 이어져요.
- 찜한 맛집이 없으면 식사 시점 위치 **근처 맛집을 자동으로 찾아** 넣고 이어서 카페도 붙여요(찾는 동안 버튼에 "맛집·카페 찾는 중…"이 보여요).
- 에버랜드처럼 오래 머무는 곳 안에서 점심을 먹는 것으로 처리되던 경우도 근처 맛집으로 바꿔 넣어요(점심이 14시 넘어 나올 수 있어요).
- 시간이 모자라면 점심 맛집+카페만, 그래도 안 되면 맛집만 넣고, 못 찾으면 식사 시간만 넣어요.
- "이 코스를 찜에 담기"를 누르면 맛집·카페도 같이 담겨요.
- 식당·카페의 영업시간은 확인하지 못해 "영업시간 미확인"으로 표시해요.

## 4. 마이 탭 지역 선택
- 지역을 고르면 지도만 움직이던 것을 **바로 검색 위치로 지정**하도록 바꿨어요.
- 안산(성포동주공10단지)·수원(호매실~금곡동 사이)·오산(청호자이)·평택(비전동)은 지정해 주신 거점 좌표로, 나머지는 도심 좌표로 찍혀요.
- 위치 이름은 괄호 없이 "안산", "수원", "오산", "평택"처럼 도시 이름만 표시돼요.
