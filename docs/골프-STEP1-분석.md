# 골프 탭 STEP 1 — 분석과 실제 데이터 수집 검증 보고

확인일: 2026-11-23. 아래 내용은 이날 직접 접속하거나 호출해서 확인한 것만 적었습니다. 확인하지 못한 것은 "확인 못 함"으로 표시했습니다.

## 1. 기존 앱 구조와 골프 탭 넣는 방법

- 탭은 `app/js/main.js` 42행의 `TABS` 배열(추천·축제·찜·코스·특가·마이)에서 정합니다. `특가`와 `마이` 사이에 `{ v: 'golf', ... }` 한 줄을 넣고, 화면은 새 파일 `app/js/ui/golf.js`로 만듭니다. 기존 탭·API·데이터·로직은 건드리지 않습니다.
- 앱에는 서버가 없습니다. 그래서 가격 수집은 지금 맛집 검증처럼 **GitHub Actions가 하루 몇 번 모아서 `app/data/golf-*.json`으로 저장**하고, 앱은 그 파일을 읽는 방식으로 만듭니다.
- 저장 키 `eodigaji.v1`은 바꾸지 않고, 골프 설정(이동시간 2시간 등)은 그 안에 새 항목으로 추가합니다.

## 3. 이동시간 (국내 차로 몇 시간)

- **카카오모빌리티 길찾기 API**로 실제 도로 기준 시간을 받을 수 있습니다. 출처: https://developers.kakaomobility.com/price/
  - 하루 무료: 자동차 길찾기 10,000건, 다중 목적지 길찾기 1,000건.
  - **미래 출발시간 길찾기**도 있어서 "토요일 아침 6시 출발" 같은 예상 시간을 받을 수 있습니다. 출처: https://developers.kakaomobility.com/guide/navi-api/future.html
  - 지금 바로 받은 값은 "실시간", 미래 시간으로 받은 값은 "예상"으로 나눠 표시합니다.
- 필요한 것: 이 API는 **REST 키**가 필요합니다. 우리 카카오 REST 키는 GitHub Actions 비밀값에만 있어서, 앱에서 바로 부르지 않고 Actions가 거점(안산·수원·오산·평택 등)→골프장 시간을 미리 계산해 파일로 저장하는 방식이 안전합니다. 사용자가 거점 외 위치에 있으면 직선거리로 1차로 거른 뒤 "예상(직선거리 기준)"으로 표시합니다.
- 카카오모빌리티 개발자 사이트에서 이 키로 길찾기 API를 쓸 수 있게 켜져 있는지는 **아직 실제 호출로 확인 못 함** → STEP 2 첫 작업으로 Actions에서 1건 호출해 확인합니다.

## 4. 해외 항공 시간 (인천 출발)

- 구글 항공편 데이터로 실제 확인했습니다 (2026-12-10 출발 기준):
  - 인천→방콕: 직항 6시간 10분 (Thai Vietjet 851, 에어프레미아 601), 직항 6시간 20분 (Trinity Airways 101)
  - 인천→세부: 직항 4시간 50분 (제주항공 2113), 4시간 55분 (세부퍼시픽 131), 마닐라 경유 8시간 10분
- 직항/경유, 편명, 소요시간이 다 나옵니다. 못 받으면 "정보 확인 불가"로 표시합니다.
- 한계: 이 조회는 지금 이 작업 도구(Firecrawl)에서 됩니다. Actions에서 자동으로 돌리려면 Firecrawl 키를 비밀값에 넣거나, 무료 항공 API(AeroDataBox 월 400건, aviationstack 월 100건 — 출처: https://aerodatabox.com/flight-api-2024 )를 써야 합니다. 항공 시간은 자주 안 바뀌어서 **주 1회 도시별로 한 번** 받아 저장하면 충분합니다.

## 5. 성공률 요약

- 국내 5곳 중 가격 자동 수집 가능 2곳 (골팡: 티타임+가격, 티스캐너: 최저가) → **40%**. 나머지 3곳은 링크로 연결.
- 해외 확인한 9곳 중 가격 수집 가능 1곳 (몽키트래블 최저가) → **약 11%**. 해외 가격은 데이터가 부족한 상태입니다.
- 이동시간: 카카오모빌리티 사용 가능 (키 활성 여부만 남음).
- 항공 시간: 실제 데이터 받기 성공.

## 6. 다음 단계 제안 (STEP 2)

1. Actions에서 카카오모빌리티 1건 호출해 키 활성 확인.
2. 골팡 국내 티타임·가격 수집기 만들기 (지역별 → 골프장 좌표는 카카오 장소검색으로 붙이기). 출처 링크와 수집 시간 함께 저장.
3. 티스캐너 최저가 수집 (브라우저로 열기).
4. 같은 골프장이 두 곳에 있으면 이름+위치로 하나로 합치고 싼 가격을 먼저 보여주기.
5. 골프 탭 화면: 국내(이동시간 조절, 기본 2시간) / 해외(나라·도시 선택). 가격 낮은 순, 20개씩 더보기, 전체 개수 표시.
6. 해외: 몽키트래블 최저가 + 항공 시간 + 공항→골프장 거리. 가격 없는 곳은 "가격 정보 없음"으로 표시 (지어내지 않음).
