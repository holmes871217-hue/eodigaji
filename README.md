# 어디가지 — 아빠 나들이 추천

가족 구성(나이·성별·가중치)과 날짜·기간, 주요 검색 위치에 맞춰 나들이 장소와 축제를 순위로 추천하는 웹앱(PWA)입니다.

- `app/` — 앱 본체. 이 폴더가 그대로 인터넷에 게시됩니다.
- `tools/serve.ps1`, `start.bat` — 내 컴퓨터에서 미리 보는 용도.

현재는 시제품 단계로, 인기·추세 숫자와 축제 날짜는 연습용 데이터입니다. 장소 사진은 위키미디어 공용(Wikimedia Commons)의 자유 이용 사진이며 각 사진의 출처는 앱 상세 화면에서 확인할 수 있습니다.
